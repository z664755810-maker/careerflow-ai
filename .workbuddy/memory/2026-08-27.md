### 关键工程决策
- **数据库双轨**：生产 PostgreSQL（asyncpg）+ Alembic 迁移；本地开发/测试用 SQLite（aiosqlite）兜底，保证零依赖可跑、CI 可绿、可移植性被验证。
- **LLM**：沿用启动包封装（OpenAI 兼容，key 仅走环境变量）。DeepSeek 余额不足，默认切**智谱 glm-4-flash（免费）**；网络探测 open.bigmodel.cn 可达(200)。调用失败优雅降级返回 503（已写测试）。
- **密码哈希**：passlib `pbkdf2_sha256`（避开 bcrypt 在 py3.13 的兼容坑），JWT 用 python-jose HS256。
- **前端**：Vue3 + Vite + TS + Pinia + Element Plus + vue-router，axios 自动带 JWT，路由鉴权守卫。
- **环境**：Docker 不可用 / psql 不可用（本机），故本地用 SQLite；Docker/compose/CI 配置按生产写法提供。
