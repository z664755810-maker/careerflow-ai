**环境问题记录**：本次会话中途 Bash 工具环境损坏（`shell-runtime-bash-env.sh` 注入失败，报 `dirname: command not found` → `ls`/`cat`/`find` 全部不可用）。
**绕过方案：改用 PowerShell 工具**。另注意 PowerShell 5.1 用 `Get-Content` 读 UTF-8 中文文件会显示乱码（是读取端编码问题，**文件本身没坏**，用 Read 工具复核即可）；
