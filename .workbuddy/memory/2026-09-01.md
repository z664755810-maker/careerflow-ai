## P0-1 文件上传解析 + P0-2 投递管理看板（落地实现）

用户"现在开始吧"→ 实现 EXTENSIONS.md 的 P0-1、P0-2，消除"手填纯文本"的玩具感、闭合求职链路。

### P0-1 文件上传解析
- 新增 `backend/app/upload_utils.py`：扩展名白名单 `.txt/.md/.pdf/.docx` + 3MB 上限 + 空内容拒绝（抛 ValueError→路由转 400）。
  PDF 用 `pypdf.PdfReader`，Word 用 `python-docx`，纯文本 utf-8/gbk/latin-1 兜底解码。
- `resumes.py` 加 `POST /resumes/upload`、`jobs.py` 加 `POST /jobs/upload`（multipart `file` + `title` 表单字段），落 `content`/`description`。
- `requirements.txt` 加 `pypdf>=4.0`、`python-docx>=1.1`。
- 前端 `ResumeView`/`JobView` 加隐藏 `<input type=file>` + 「📎 上传文件」按钮 + 成功/失败提示；`api.ts` 加 `uploadResume/uploadJob`。

### P0-2 投递管理看板
- `models.py` 新增 `Application`（`resume_id`/`job_id` 外键 SET NULL + `resume_title`/`job_title` 快照 + `status` + `applied_at` + `notes`）+ 常量 `APPLICATION_STATUSES`。
- `schemas.py` 加 `ApplicationCreate/Update/Out`，状态校验用 pydantic `@field_validator`（非法→422，非 500）。
- `api/applications.py`：`POST/GET/GET{id}/PUT/DELETE`，全按 `owner_id` 隔离（越权 404），`GET` 支持 `?status=` 过滤（非法 400）。
- `seed.py` 加 `SAMPLE_APPLICATIONS` 5 条（覆盖全部状态，含 applied_at 偏移），让看板开箱有数据。
- 前端新增 `ApplicationsView.vue` 看板（5 列状态分栏 + 统计卡 + 卡片内联改状态/编辑/删除）；`DashboardView` 加「投递记录」卡；`App.vue`/`router` 注册 `/applications` 导航。

### 关键修复：seed 门控解耦
- 原 `main.py` 中 seed 仅在 `_HAS_FRONTEND`(有 static 目录) 时运行；但 Render Docker 镜像只装后端、无 static 目录 → 线上永远不灌数据。
  改为仅由 `AUTO_SEED` 控制（与前端目录解耦），确保 `AUTO_SEED=1` 时（含 Render）能正常 seed。测试仍 `AUTO_SEED=0` 不受影响。
